# Frontal SDK (Go) Skill

Agent skill for building Go code against the Frontal API with `github.com/frontal-labs/sdk-go/v2`.

## Files

- `SKILL.md`: when to use the SDK, install, quick start, configuration, services, errors, retries, pagination, streaming, testing.
- `references/API_ENDPOINTS.md`: all 635 inventory operations across 17 services.
- `references/CLIENT_PATTERNS.md`: options, environment variables, request shape, typed services, bound operations, streams, pagination, polling.
- `references/ERROR_HANDLING.md`: `APIError` fields, decoding rules, category helpers, retryability.
- `assets/go.mod`: consumer module template (`go 1.23`, requires `v2.0.0`).
