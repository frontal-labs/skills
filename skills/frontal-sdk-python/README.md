# frontal-sdk-python

Agent skill for the Python SDK for the Frontal API (`frontal` on PyPI,
imported as `frontal_sdk`). Based on upstream SDK version 1.0.0.

## Files

- `SKILL.md`: when to use the SDK, install, quick start, configuration,
  services, errors, testing.
- `references/API_ENDPOINTS.md`: service namespaces, method conventions,
  models.
- `references/CLIENT_PATTERNS.md`: client construction, sync vs async, AI
  helpers, agents, workflows, functions, pagination, polling.
- `references/ERROR_HANDLING.md`: error classes and fields, retry and replay
  rules, circuit breaker.
- `assets/pyproject.toml`: consumer project template.
