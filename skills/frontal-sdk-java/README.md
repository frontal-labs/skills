# frontal-sdk-java

Agent skill for the Java 17+ Frontal SDK (`dev.frontal:frontal-sdk`, version 2.0.0). Covers the root `Frontal` client, configuration, service accessors, typed errors, pagination, SSE streams, and retries.

## Files

- `SKILL.md`: entry point. When to use, installation, quick start, configuration, services, errors, testing.
- `references/API_ENDPOINTS.md`: accessors, nested resources, Functions routes, known gaps between the SDK catalog and the shared OpenAPI spec.
- `references/CLIENT_PATTERNS.md`: method naming, query parameters, request bodies, pagination, streams, polling, custom auth.
- `references/ERROR_HANDLING.md`: exception hierarchy, status mapping, retry rules, diagnostics.
