# frontal-cli

Agent skill for the Frontal CLI (`frontal-cli` on npm, binary `frontal`). Covers installation, authentication, configuration, the command set, and common workflows.

## Files

- `SKILL.md`: when to use the CLI, install channels, authentication, configuration, and common workflows.
- `references/COMMAND_REFERENCE.md`: per-command reference with flags and exit behavior.
- `references/CONFIGURATION.md`: config files, environment variables, and precedence.
