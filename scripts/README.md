# Scripts

This directory contains utility scripts for managing Frontal Agent Skills.

## Scripts

- `validate-skills.js`: Validates all skills in the `skills/` directory. Checks frontmatter, required fields, naming conventions, and directory structure. Run with `npm run validate`.
- `list-skills.js`: Lists all available skills with their descriptions, categories, and paths. Run with `npm run list`.
- `install-skills.js`: Installs skills to the local `.skills/` directory. Run with `npm run install`.
